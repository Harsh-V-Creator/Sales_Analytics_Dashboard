# Sales_Analytics_Dashboard
Interactive Power BI dashboard analyzing sales of computer hardware components (CPU, SSD, HDD, RAM, GPU, monitors, etc.) across Indian states and union territories.
Key features:

Order-level data from Jan 2020 – Dec 2022
Metrics: Sales, Cost, Quantity, Profit
Dimensions: State, Category, Brand, Product, Order Status, Supervisor
Supporting tables: State code mapping & Supervisor image list.
